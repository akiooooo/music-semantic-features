# Семантические признаки музыкальных треков

Тестовое исследование двух Spotify-плейлистов для задачи музыкальных рекомендаций. В проекте собраны 100 позиций, извлечены признаки 30-секундных preview, построены CLAP-эмбеддинги и две модели похожести.

## Источники

- [Daily Mix 6](https://open.spotify.com/playlist/37i9dQZF1E39FJtUzeh2UV?si=_zf3vFIMT5y3A2CdbfpPuA), первые 50 позиций
- [VILLIAN Radio](https://open.spotify.com/playlist/37i9dQZF1E4wwkchMkSBWv?si=leedN1noRZGw2fTD14AyZQ), первые 50 позиций

Плейлисты алгоритмические и могут обновляться. Для анализа используется сохранённый снимок с датой сбора. В исходных 100 позициях есть три пересечения, поэтому после удаления повторов остаётся 97 уникальных треков.

Ограничения на жанр и количество треков артиста не применялись: задача фиксирует первые 50 позиций каждого источника. В фактическом снимке один artist string встречается максимум восемь раз.

## Пайплайн

`librosa` извлекает tempo, RMS, onset rate, спектральные характеристики, chroma и 13 MFCC. Предобученная модель `laion/clap-htsat-unfused` создаёт 512-мерные эмбеддинги и zero-shot метки:

- genre
- mood
- context
- atmosphere

Для поиска соседей сравниваются два пространства:

- 21 стандартизованный low-level признак
- CLAP embedding

Похожесть считается через cosine similarity. Пространство CLAP дополнительно показано через UMAP и t-SNE.

## Результаты

Датасет смещён в hip-hop и energetic: это свойство заданных плейлистов, а не искусственная балансировка.

CLAP чаще сохраняет семантические метки у ближайших соседей:

| Метрика | Low-level | CLAP |
|---|---:|---:|
| Совпадение genre у ближайшего соседа | 0.608 | 0.784 |
| Совпадение mood | 0.763 | 0.845 |
| Совпадение context | 0.454 | 0.598 |
| Ближайший сосед из того же плейлиста | 0.467 | 0.518 |

Среди отдельных low-level групп MFCC показали 0.516 совпадения плейлиста у ближайшего соседа, ритм и энергия — 0.500, спектральные признаки — 0.424. Все 21 признак вместе дали 0.467, поэтому добавление коррелирующих столбцов не обязательно улучшает похожесть.

Silhouette score по источнику близок к нулю для обоих представлений. Значит, плейлисты не образуют хорошо разделимых кластеров и содержат похожую музыку.

Семантические метки получены той же моделью CLAP, поэтому их совпадение не является независимой оценкой. Для полноценной проверки нужны ручные оценки похожести или история прослушиваний.

## Ограничения

- плейлисты могут измениться после даты снимка
- анализируется только 30-секундный preview
- zero-shot метки не проверены ручной разметкой
- выборка жанрово узкая
- 97 уникальных треков мало для устойчивой оценки рекомендаций
- нет пользовательских оценок и истории прослушиваний
