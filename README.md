# Семантические признаки музыкальных треков

Учебный проект о том, какие признаки аудио можно использовать в контентных рекомендациях. В проекте 100 треков из открытого Deezer API, признаки 30-секундных фрагментов, семантическая разметка, EDA и поиск похожих треков.

[Открыть ноутбук в Google Colab](https://colab.research.google.com/github/akiooooo/music-semantic-features/blob/main/music_analysis.ipynb)

## Что находится в проекте

- `music_analysis.ipynb` — основной Colab-ноутбук с кодом, графиками и выводами
- `collect_dataset.py` — отдельный скрипт для повторного сбора метаданных
- `data/music_dataset.csv` — исходные 100 треков
- `data/music_dataset_enriched.csv` — итоговый датасет с аудио- и семантическими признаками
- `data/audio_features.csv` — признаки, извлечённые из preview
- `data/experiment_metrics.json` — метрики эксперимента
- `results/figures/` — графики из ноутбука

## Данные

Использованы чарты Deezer для 10 жанров: pop, rap/hip-hop, rock, dance, r&b, alternative, electro, folk, jazz и classical. В каждом жанре по 10 треков. На одного исполнителя приходится не больше двух треков.

Deezer API возвращает метаданные, ссылку на страницу трека и 30-секундный аудиофрагмент. Ключи API не нужны. Аудиофайлы в репозиторий не добавляются, сохраняются только ссылки и извлечённые признаки.

## Признаки

Из preview через `librosa` извлекаются tempo, RMS, плотность атак, спектральные характеристики, chroma и 13 MFCC. По нормализованным значениям строятся простые интерпретируемые метки настроения, контекста и атмосферы.

Для поиска похожих треков используется cosine similarity на стандартизованных признаках. Пространство дополнительно показано через UMAP и t-SNE.

## Результат эксперимента

Ближайшие соседи часто совпадают по плотности и тембру, но жанровые и семантические группы разделяются слабо. Silhouette score оказался около нуля или ниже нуля. Это значит, что выбранных low-level признаков недостаточно для надёжного описания музыкальной семантики.

Практический вывод: tempo, RMS, onset rate и MFCC подходят для первого content-based baseline, но для более качественных рекомендаций нужны обученные аудио-эмбеддинги и пользовательские оценки похожести.

## Запуск

В Colab достаточно открыть ноутбук и выбрать `Runtime → Run all`.

Локальный запуск:

```bash
pip install -r requirements.txt
python collect_dataset.py
jupyter notebook music_analysis.ipynb
```

Для сохранения preview локально:

```bash
python collect_dataset.py --download-previews
```

## Ограничения

- выборка маленькая и состоит из текущих чартов
- жанр задан разделом Deezer, а не ручной разметкой
- анализируется один 30-секундный фрагмент
- семантические классы заданы эвристиками
- без пользовательских данных нельзя измерить реальную полезность рекомендаций
- preview URL со временем могут измениться
